# NewsProject

Локальное приложение, которое превращает поток новостей в умные дайджесты.

Вы задаёте источники (новостные сайты и публичные Telegram-каналы) и тему или
вопрос — приложение собирает свежие новости, отбирает по смыслу релевантные и
просит нейросеть составить один плотный дайджест со ссылками на
первоисточники. Работает целиком на вашем компьютере: без бэкенда и облака.

## Возможности

- **Любые источники** — лента обычного сайта (парсится автоматически), RSS
  или Telegram-канал; понимает «стены входа» вроде dzen.ru.
- **Отбор по смыслу** — тема «спорт» находит футбол и хоккей даже без слова
  «спорт» в заголовках: релевантность определяет модель, а не поиск по
  подстрокам.
- **Вопросы** — спросите «что происходит с ценами на бензин?» и получите
  ответ, построенный только на фактах свежих новостей, с кликабельными
  цитатами `[1]`.
- **Ответ на вашем языке** — пишете по-русски, дайджест по-русски.
- **Подсказки** — если тема ничего не дала, приложение предложит темы,
  которые ваши источники действительно освещают сейчас.
- **История чатов** — все диалоги сохраняются локально.

## Установка и запуск

Нужен Python 3.11+.

```bash
pip install -r requirements.txt
python -m app.main        # или двойной клик по run.bat
```

При первом запуске добавьте API-профиль кнопкой **+ Add API** в левом меню.
Подойдёт любой совместимый с OpenAI API: GigaChat, YandexGPT, OpenRouter,
DeepSeek, локальные модели (Ollama) и другие.

## Как пользоваться

1. В поле внизу чата введите тему («энергетика»), вопрос («что с ценами на
   бензин?») или оставьте пустым — будет общий дайджест за период.
2. В левом меню настройте источники, период (24 часа / 3 дня / 7 дней / всё
   время), длину и стиль дайджеста.
3. В ответе кликните цитату `[1]` — откроется оригинальная статья.

## Конфиденциальность

Ключи API, настройки и история чатов хранятся только на вашем компьютере
(`settings.json`, `chats.json`) и в репозиторий не попадают — они в
`.gitignore`. Шаблон настроек без секретов — `.env.example`.
